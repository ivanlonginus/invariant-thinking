# Glossary

**Analogy Break**
A condition under which a proposed structural mapping stops preserving what matters for the current reasoning task.

**Boundary**
The assumptions and context within which a claim is intended to hold.

**Constraint**
A condition that restricts the available solution space.

**DELTA Protocol**
The five-step operational method: Decompose, Extract, Link, Test, Acquire.

**Implementation**
A concrete realization of a capability.

**Invariant**
A property treated as preserved across a specified transformation set within a specified boundary.

**Invariant Boundary**
The explicit validity region of an invariant claim.

**Invariant Map**
A structured artifact documenting an ITF analysis.

**Invariant Stack**
The six-layer analytical model: Product/Interface, Implementation, Mechanism, Pattern, Constraint, Invariant.

**Learning Delta**
The knowledge still required after valid prior knowledge has been transferred.

**Mechanism**
The process through which a system produces an outcome.

**Pattern**
A recurring organization of mechanisms that addresses a class of problems.

**Transfer**
Reuse of prior knowledge in a new context after checking that the relevant mapping remains valid.

**Transformation**
A defined change between systems, states, implementations, representations, or contexts.
