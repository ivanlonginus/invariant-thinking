# Non-Claims

Invariant Thinking deliberately does **not** claim that:

1. everything has already been invented;
2. new technologies are merely marketing;
3. all implementations of the same pattern are equivalent;
4. fundamentals literally never change;
5. abstraction is always superior to implementation knowledge;
6. every domain can be reduced to a small universal set of invariants;
7. the DELTA Protocol has already been scientifically proven to accelerate human learning;
8. a lower-level structural similarity implies equal performance, economics, safety, social impact, or capability;
9. memorization is useless;
10. experts should ignore new terminology or product-specific semantics;
11. the framework has invented the general concepts of invariance, abstraction, analogy, schemas, or transfer learning;
12. a candidate invariant is true merely because it sounds fundamental.

The framework is intended to make structural claims **more explicit and easier to challenge**, not to make them immune to criticism.
