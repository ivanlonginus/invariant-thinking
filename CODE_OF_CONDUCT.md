# Code of Conduct

This project exists to test and improve ideas, not to protect them from criticism.

Participants are expected to:

- critique claims, definitions, evidence, and reasoning rather than people;
- represent opposing arguments accurately;
- disclose uncertainty and conflicts of interest when relevant;
- avoid harassment, discrimination, threats, or personal attacks;
- welcome counterexamples and negative results.

Maintainers may remove contributions or participation that repeatedly violate these expectations.

For conduct concerns, contact the maintainer through the GitHub profile associated with this repository.
