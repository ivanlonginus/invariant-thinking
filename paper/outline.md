# Whitepaper Outline — Invariant Thinking

This directory is intentionally an outline, not a paper pretending to contain evidence that has not yet been collected.

1. Abstract
2. Problem: learning under accelerated implementation churn
3. Intellectual context
4. Framework definitions
5. Invariant Stack
6. Transformation and Invariant Boundary
7. Learning Delta
8. DELTA Protocol
9. Worked case studies
10. Negative transfer and analogy breaks
11. Limitations
12. Research hypotheses
13. Evaluation methodology
14. Discussion
15. Conclusion
16. References

## Publication threshold

Do not call the document an empirical theory paper until it includes actual evidence. Before that point, describe it as a framework paper, position paper, or conceptual proposal.
